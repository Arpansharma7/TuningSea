# TuningSea Studio

A complete interactive front-end prototype for TuningSea, styled with the monochrome “Chrome Mission” design system.

## Run

Open `index.html` directly in a modern browser. No build step or dependency installation is required.

## Included product areas

- Projects and guided project creation
- Dataset import and quality review
- Curated model catalog and compatibility recommendations
- Machine Sense hardware verdicts
- Interactive training controls, metrics, telemetry, and checkpoints
- Side-by-side model evaluation
- Local model library and export targets
- Privacy, reliability, and storage settings
- Responsive desktop/mobile layouts and reduced-motion support

Application state is stored locally in the browser.
